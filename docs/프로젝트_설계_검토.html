사용자 취향 기반 시간표 추천 설계 검토

01구현 순서 제안

단계구현 범위완료 기준
기본 생성필수 과목·시간 충돌 검사필수 조건을 만족하는 시간표와 주간 화면
선호 추천가중치 반영·Top-K·결과 비교서로 다른 후보, 점수와 일치하는 추천 이유
조건 확장이동거리·수강신청 실패 시 재추천이동 비용 반영, 성공 분반 유지·실패 분반 제외

02핵심 쟁점

실제 강의 데이터

숭실대 강의 데이터 활용 예정. 수집 경로·대상 학기·갱신 기준 미정.

권고소규모 실제 샘플 확보 후 수집 범위 확정. 시간·강의실 미정 항목의 처리 기준 명시.

필수·선호 조건

필수·희망 과목의 구분 불명확. 학점 제한은 역할표에만 명시.

권고반드시 포함할 과목과 선택 가능한 과목 구분. 학점 조건의 적용 범위 합의. 필수 조건의 임의 완화 금지.

점수·추천 이유

가중합 방식은 제시됐으나 공강·연강·이동 비용의 정의와 점수 척도 미정.

권고항목별 계산식·단위·가중치·점수 내역 공유. 추천 이유는 최적화에 사용한 값으로 생성.

이동거리·가능성

연속 수업의 거리 비용은 제시. 거리 산정과 실제 이동 가능성의 판단 기준 미정.

권고거리 선호와 이동 불가 조건 구분. 이동 가능성을 보장하려면 수업 간격과 이동 시간 비교.

Top-K 차별성

여러 후보 제공은 명시. 중복 제거·후보 간 차이·동점 처리 기준 미정.

권고동일 분반 조합 제외. 후보 간 차이 기준과 K개 미만일 때의 표시 방식 합의.

재추천 변경 비용

성공 분반 고정·실패 분반 제외는 명확. ‘변경 최소화’의 지표와 선호 점수 간 우선순위 미정.

권고변경 분반 수 최소화를 우선 적용하고, 동률이면 선호 점수 비교.

03역할 경계 조정안

담당책임 범위인계 기준
1 · 데이터수집·정규화·유효성 검사학기·과목·분반 ID, 학점, 복수 수업 시간, 위치 데이터와 예제
2 · 최적화CP-SAT 제약·목표함수·단일 계산 엔진제외·고정 분반 등 조건을 받아 선택 분반·결과 상태·점수 내역 반환
3 · 결과·대안Top-K 요청·중복 기준·대안 시나리오·비교와 설명2번 엔진 호출로 재추천. 성공 분반 유지와 결과·설명 일치 검증
4 · UI·통합조건 입력·주간 시간표·비교 화면·전체 연결정상 결과·해 없음·계산 미확정·입력 오류의 전체 흐름
  • 2·3번 경계: 최적화 제약과 점수 계산은 2번이 소유. 3번은 동일 엔진·점수 내역을 재사용.
  • 공동 합의: 데이터 필드·요청/응답·실명 담당자·중간 인계일. 각 담당자가 자체 테스트와 오류 수정 책임.

04검증 기준

생성·추천 정확성

  • 작은 고정 데이터에서 정답 시간표와 결과 대조
  • 복수 요일 수업 충돌·동일 과목 중복·필수 과목·학점 조건 검사
  • 선호 가중치 변경 시 점수와 순위 변화 확인
  • Top-K 중복 제거·추천 이유와 계산 값 일치 확인

대안·실패 처리

  • 수강신청 성공 분반 유지·실패 분반 제외 확인
  • 대체 가능한 결과 중 기존 시간표 변경량 비교
  • 최적해·가능한 해·해 없음·미확정 구분. 시간 초과를 해 없음으로 단정하지 않음.
  • 데이터 누락과 입력 오류를 정상 결과로 처리하지 않음

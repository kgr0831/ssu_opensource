02 / 진로 기반 과목 선택

진로와 학습 단계에 맞는 과목 탐색

AI·컴퓨터비전 / 데이터 분석 / 웹·백엔드

1. 관심 분야·단계 선택

기초 → 핵심 → 심화 과목 탐색

2. 이미 이수한 과목 제외

다시 들을 필요 없는 과목 제거

3. 시간표 조건에 적용

학점·요일 조건을 유지하며 조합 탐색

현재는 진로별 예시 매핑. 공식 선수과목 판정과 강의계획서·외부 진로 정보 검색은 후속 개발 범위.

진로 추천 과목의 필수 수강을 강제하지 않음.02

03 / 학기 캘린더

반복 시간표에 날짜별 변경 반영

학기 기간 입력 → 수업 일정 생성 → 휴강·시험·보강·개인 일정 관리

변경 범위 구분

이번 일정만 / 같은 요일의 이후 반복 일정

일정 중복 확인

휴강은 제외하고 수업·시험·개인 일정 비교

변경 내용은 직접 입력. 일정은 현재 브라우저에 저장.03

04 / 수강 경험

수강 조언을 내 시간표 조건에 연결

과목 조합 참고 → 관심 과목 적용 → 선택 이유 기록

실제 학과별 게시판은 계정·공유 동의·신고 및 관리 기능을 갖춘 후 확장.

추천 근거로 제공하되, 강의 난이도·성적·수강 자격을 보장하지 않음.04

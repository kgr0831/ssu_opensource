# 숭실대 시간표 추천 데모

원하는 요일·시간·학점과 관심 분야를 입력하면 수업이 겹치지 않는 시간표 3개를 추천합니다. AI 추천은 본인의 Codex 계정으로 실행합니다.

[서비스 제안서 — 실제 화면 중심 HTML](docs/시간표_추천_제안서.html)

HTML 파일 하나만 내려받아 열면 이미지가 포함된 6개 페이지로 확인할 수 있습니다. 좌우 화살표로 이동하고 화면 이미지를 클릭하면 확대됩니다.

## 실행

Windows에 **Google Chrome, Node.js 20 이상, Codex CLI**가 필요합니다.

1. 이 저장소를 내려받고 압축을 풉니다.
2. **시간표 데모 시작.bat**를 더블클릭합니다. 준비가 끝나면 크롬이 열립니다.
3. **Codex 연결**을 눌러 브라우저에서 로그인·승인합니다. 이미 로그인되어 있으면 자동 연결됩니다.
4. 원하는 조건을 입력하고 **AI로 시간표 짜기**를 누릅니다.

**터미널 창을 닫거나 Ctrl+C를 누르면 데모가 종료됩니다.** 추가 npm 패키지 설치는 필요하지 않습니다. AI 없이 사용하려면 조건을 직접 설정하고 **조건대로 기본 추천**을 누릅니다.

## 요청 예시

- “수요일만 수업을 듣고, 전공 6학점과 교양 2학점으로 골라줘.”
- “전공 9학점, 교양 4학점으로 짜줘. 교양은 알아서 추천해줘.”
- “교양만 6학점 듣고 싶어. 독서와 글쓰기에 관심이 있어.”
- “월요일과 수요일에만 등교하고 총 12~14학점을 듣고 싶어.”

## 데이터와 범위

- **진로 기반 과목 탐색:** AI·컴퓨터비전, 데이터 분석, 웹·백엔드의 단계별 예시 과목을 추천 조건에 적용하고 이수 과목 제외
- **학기 캘린더:** 시간표를 학기 수업 일정으로 저장하고 휴강·시험·보강·개인 일정, 이번 일정/이후 반복 변경 및 시간 겹침 확인
- **수강 경험:** 가상 조언의 과목 조합 적용과 내 시간표 기록. 실제 선배 후기나 공개 게시판은 아님
- **추가 기능 — ICS 내보내기:** 변경을 반영한 학기 일정을 파일로 다운로드. 휴강·취소 제외, 자동 동기화 없음

일정과 내 기록은 현재 브라우저에만 저장됩니다. 브라우저 데이터를 지우거나 다른 주소·포트로 접속하면 기존 기록을 사용할 수 없습니다.

숭실대 AI소프트웨어학부 전공 32개와 교양 18개, 총 **50과목·150개 가상 분반**을 제공합니다. 과목명·학점은 공식 교육과정을 참고했으며, **수업 시간·분반·강의실은 데모용 가상 데이터**입니다. 실제 수강 신청이나 졸업 요건 판정에는 사용할 수 없습니다.

AI가 요청을 조건으로 해석하고, 코드가 유효한 후보를 생성한 뒤 AI가 추천 이유를 설명합니다. AI는 이 데모의 추천 기능에만 사용하며 실제 개발의 AI 도입 방식은 미정입니다.

## 개발 및 검증

```powershell
cd timetable-demo
npm start
npm test
```

로컬 주소는 `http://127.0.0.1:4317`입니다. 계정 인증 정보는 Codex가 관리하며 이 앱은 인증 파일을 읽거나 복사하지 않습니다.
